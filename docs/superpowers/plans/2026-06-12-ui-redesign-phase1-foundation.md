# UI Redesign — Phase 1: Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `src/index.css` with a self-hosted Tailwind v4 `@theme` design-token layer (Kriya v2.2 palette + Geist/Geist Mono/Latin Modern Math fonts), add shadcn/ui tooling (`cn()`, Button, Tooltip, ScrollArea primitives), and add Framer Motion as a dependency — all additive, with zero visual change to the existing app.

**Architecture:** New `src/styles/theme.css` becomes the single token source of truth (Tailwind v4 `@theme` block) plus a verbatim "legacy compatibility" `:root` block so every existing `.module.css` file keeps resolving its old `var(--ee-*)`, `--indigo`, `--ui-font`, etc. names unchanged. `main.tsx` swaps its CSS import. shadcn/ui is initialized against that file and three primitives are generated into `src/components/ui/`. No file under `src/components/{Toolbar,ExpressionZone,Editor,ActionBar,MathPreview,Utility}/` or `src/App.tsx` is modified.

**Tech Stack:** Vite 5 + React 18 + TS 5, Tailwind CSS v4 (`@tailwindcss/vite`), shadcn/ui (Radix primitives + `class-variance-authority` + `clsx` + `tailwind-merge`), Framer Motion, pnpm 9.

**Source of truth for design tokens:** `docs/superpowers/specs/2026-06-12-ui-redesign-phase1-foundation-design.md` (already reviewed — all values below are taken from it).

To keep ActionBar pixel-identical, the legacy `:root` block must be declared **after** the `@theme` block in `theme.css` so its `--shadow-xs`/`--shadow-sm` win the cascade for existing consumers.
- Geist + Geist Mono variable `.woff2` files come from the `geist` npm package (`geist@1.7.2`, MIT).
